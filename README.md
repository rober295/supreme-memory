# God-level upgrade 2.6

Фітнес-RPG на Python + Kivy (Windows / Android). Дані зберігаються локально.

## Що працює
- перший запуск: питання про вік, вагу, зріст, досвід і важкість (легке / середнє / важке);
- план на день зі структурою: вправи, підходи, повторення або час (залежить від досвіду та важкості);
- картки вправ: «Техніка» і «Почати»; екран вправи з таймером підходу та таймером відпочинку;
- таймер не стартує сам; вихід із вправи повертає до тренування, а не на головну; час не губиться при переході;
- XP лише за реально виконані підходи (+ бонус за повне тренування), без накрутки;
- рекорди по вправах, порівняння з минулим підходом;
- календар (колір дня, подробиці по натисканню), серія (дні відновлення її не рвуть);
- рівні, значки з рідкістю, титули з закріпленням, жартівливі титули за повернення без осуду;
- сон: години, якість, поради, середнє за тиждень;
- «режим на сьогодні»: відпочити / легко / помірно / на повну — з урахуванням сну та навантаження;
- офлайн-тренер: техніка, м'язи, помилки, легший варіант, відпочинок, кріпатура; пам'ятає тему («а які помилки?»);
- бібліотека з 11 вправ, відео-пошук (відкривається браузер);
- кнопка «Назад» Android, нижнє меню, захист від збоїв екрана.

## Нове в 2.6
- титули за монстрів (перший слиз, кожен бос, 10/50/150 перемог, колекціонер);
- картки героїв аніме з фразами: шанс 10% зі звичайних монстрів, 50% з босів;
- вікно удару: 6 с (боси 5 с), запізнився — урон вдвічі менший;
- онлайн-ШІ-тренер: у чаті встав свій API-ключ Anthropic, без ключа чи мережі відповідає офлайн-тренер;
- виправлено: монети й прогрес бою зникали після перезапуску.

## Ще не зроблено
Підрахунок віджимань камерою, магазин і броня, локації, push-сповіщення, випадкові нагороди з шансами, синхронізація.

## Запуск на комп'ютері
```bash
pip install -r requirements.txt
python main.py
python test_logic.py      # перевірка логіки
```

## APK для Android
Варіант 1 (без Linux): завантаж папку проєкту в репозиторій GitHub → вкладка Actions → «Build APK» → Run workflow.
Готовий APK буде в Artifacts. Файл `.github/workflows/build-apk.yml` вже є.

Варіант 2: Linux або WSL2:
```bash
pip install buildozer
buildozer android debug
```
APK з'явиться в `bin/`. Перша збірка довга (завантажує Android SDK/NDK).
На телефоні дозволь встановлення з невідомих джерел.

Не тренуйся через біль. Неповнолітнім план варто узгодити з тренером або лікарем.
